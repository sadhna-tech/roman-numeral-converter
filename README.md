# Roman Numeral Converter

A simple Python project that converts:

- Roman Numerals → Integers
- Integers → Roman Numerals

This project is perfect for beginners who want to practice strings, dictionaries, loops, and functions.

## Features

- Convert Roman numerals to decimal numbers
- Convert decimal numbers to Roman numerals
- Input validation
- Easy-to-read code
- Beginner-friendly

## Supported Range

1 - 3999
